Reproductive Health Application

By: Sylvia Martin

About the Project

This project is a mobile application focused on sexual and reproductive health. It provides a digital platform where users can log key health data, view personalised insights, access educational resources, and set reminders for checkups and medication.

The goal of the app is to encourage users to take a more proactive, informed, and organised approach to managing their reproductive health.

Key Features

  • User authentication with email and password
  • Reproductive health tracking
  • Lifestyle tracking (sleep, water, diet, fitness)
  • Reminders and notifications
  • Educational articles and supplement information
  • Personalised statistics and insights

Technologies

  • React Native
  • Wikipedia API
  • Node.js
  • Express
  • MongoDB
  • Mongoose
  • JSON Web Tokens
  • bcrypt
  • Git & GitHub
