About the Project

This is a full-stack mobile application designed to support users in tracking, understanding, and managing their reproductive health across different life stages.

The platform provides personalised health logging, real-time insights, educational resources, and automated reminders to help users take a more informed and structured approach to their wellbeing.

It is built as an end-to-end system using a React Native frontend, a Node.js and Express backend, and a MongoDB cloud database, with secure authentication and API-based communication between layers.

System Overview

The application is implemented as a full-stack system with a mobile frontend, backend API layer, and cloud-based database infrastructure.

  • Frontend: React Native application built with Expo for cross-platform mobile deployment
  • Backend: Node.js and Express REST API handling requests and application logic
  • Database: MongoDB Atlas used for secure and persistent cloud data storage
  • Authentication: JWT-based session management with encrypted password storage using bcrypt

The system follows a client–server architecture where the mobile application communicates with the backend API, which processes requests and interacts with the database before returning responses to the frontend.

Generates trends and statistics based on user health data.

Technologies

The application was built using a modern full-stack JavaScript architecture.

Frontend: React Native, Expo

Backend: Node.js, Express

Database: MongoDB, Mongoose, Atlas cloud deployment

Authentication: JWT, bcrypt

APIs: Wikipedia API

Tools: Git, GitHub, npm

Security

Security was implemented throughout the application to ensure safe handling of user data and secure authentication.

  • Password Security: Passwords are encrypted using bcrypt before being stored in the database.
  • Authentication: JWT tokens are used to manage secure user sessions.
  • Protected Routes: Middleware ensures only authenticated users can access sensitive endpoints.
  • Data Protection: Environment variables are used to securely store sensitive configuration data.
